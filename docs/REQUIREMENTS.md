# AadhaarAssist Requirements

## Functional Requirements

1. The system must support at least 5 Aadhaar rule records.
2. The system must retrieve documents for 4 update categories.
3. The system must support searching records by query.
4. The system must return document details using unique IDs.
5. The system must provide health and readiness endpoints.

## Non-Functional Requirements

1. API responses should complete within 2 seconds under normal load.
2. The system must pass at least 6 automated tests.
3. The application must never store real Aadhaar numbers.
4. The system must support Tamil and English queries.
5. The system must achieve at least 95% accuracy on 40 test scenarios.
